# Monitor AMBA 2026

Sistema de inteligencia político-institucional
para los 40 municipios bonaerenses del AMBA.

Tres capas de análisis:
- Política institucional y gobernabilidad.
- Transparencia, seguridad y control.
- Historial de cambios y alertas.
